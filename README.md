# Thumbnail Icon Pack

20 clean SVG icons for thumbnails and slides

## Overview
Thumbnail Icon Pack is a set of 20 clean SVG icons designed for thumbnails and slides. It helps creators add consistent visual accents to YouTube thumbnails, presentation slides, and social graphics without redrawing assets. Files are delivered as editable SVG source with a preview sheet for quick selection.

## Use cases
- You need matching icons for a YouTube thumbnail series and want consistent stroke weight across uploads.
- You are building a slide deck and need simple icons to label sections without cluttering text.
- You are making Instagram carousel graphics and want reusable SVG icons that scale cleanly.

## How to use
1. Download the pack and unzip the folder.
2. Open the preview sheet to choose an icon by name or visual.
3. Drag the SVG into your design tool or slides and adjust color or size as needed.

## What is included
- SVG source
- Consistent stroke width
- Preview sheet
